## 無料と有料の境界 (第2回の本題)

第1回の shadcn/ui には有料版が無く、この軸は空振りしました。MUI では本題になります。

| プラン | 価格 (公式ページ・2026-08-02 取得) |
|---|---|
| Community | 無料 |
| **Pro** | **$299 / 年 / 開発者** |
| Premium | $599 / 年 / 開発者 |
| Enterprise | $1,399 / 年 / 開発者 |

**よくある誤解: 「グラフや日付入力は有料」ではありません。**
各系統に MIT の無料版があります。npm の `license` を直接確認した結果:

| 無料 (MIT) | 有料 (商用ライセンス) |
|---|---|
| `@mui/x-data-grid` | `@mui/x-data-grid-pro` |
| `@mui/x-date-pickers` | `@mui/x-date-pickers-pro` |
| `@mui/x-charts` | `@mui/x-charts-pro` |
| `@mui/x-tree-view` / `@mui/x-scheduler` | — |

Pro で増えるのは**表の高度な機能**が中心です。列の固定・列のリサイズ・列のグループ化・
行の並べ替え・行の固定・セル選択・ヘッダフィルタ・行/セルの編集・Excel 書き出し・
ツリーデータ・行グループ化・集計。Premium はさらにピボットや大規模データ向けが加わります。

**判断の目安**: 一覧を表示して並べ替える程度なら無料で足ります。
「業務用の分厚い表」— 列を固定して横スクロール、Excel に出す、行をグループ化して集計 —
を作り始めた時点で Pro を検討することになります。

## 7軸の結果

### 軸1 デザイン (採点しない)

Material Design の見た目です。3実装を並べたときの特徴:

| 箇所 | ライブラリ無し | shadcn/ui | MUI |
|---|---|---|---|
| 入力欄のラベル | 欄の上に置く | 欄の上に置く | **枠の中に入り、入力すると枠線の上へ動く** |
| タブ | 下線だけ | 角丸の箱に入ったピル型 | 下線 + 選択色 |
| ボタン | 素の押しボタン | 黒背景の角丸 | 青の塗り + 影 |
| カレンダー | 画面に描かれない | ページ内に描かれる | ページ内に描かれる (日付が丸) |
| トースト | 右下の枠付きテキスト | アイコン付きカード | 塗りつぶしの帯 |

### 軸2 開発速度

| | ライブラリ無し | shadcn/ui | MUI |
|---|---|---|---|
| 自作行数 | 610 | 340 | **307** |
| 取り込み行数 | 0 | 1,472 | **0** |
| 依存パッケージ (dep + dev) | 2 + 6 | 17 + 7 | 8 + 7 |

導入は**2手**です。

```bash
npm create vite@latest mui -- --template react-ts
npm i @mui/material @emotion/react @emotion/styled @mui/icons-material @mui/x-date-pickers dayjs
```

**所要時間は測っていません** — 慣れの差が混ざるためです。

### 軸3 自由度

| 課題 | MUI |
|---|---|
| ブランド色1つで全体を差し替え | 可能 / **1箇所** (`createTheme` の `palette.primary`) |
| 全部品の角丸を 0 に | 可能 / **上と同じ1箇所** (`shape.borderRadius`) |
| ダイアログの開閉アニメを差し替え | 可能 (`TransitionComponent` が公式の差し替え口) |

**テーマの入口が1つにまとまっている**のが MUI の設計です。
shadcn/ui は CSS 変数を明暗2つぶん書き換えるので、触る箇所が増えます。

差し替えの考え方も違います。shadcn/ui は**部品のソースが手元にある**ので直接書き換えます。
MUI は**公式が用意した口**を使います。前者は何でもできる代わりに本家の修正が自動で来ません。
後者は用意された範囲でだけ変えられます。

### 軸4 技術構成

React 専用。スタイルは Emotion (CSS-in-JS) なので、ビルド成果物に**CSS ファイルが出ません**。
すべて JS に含まれます。Next.js での利用も公式に案内されています。

### 軸5 アクセシビリティ

| | ライブラリ無し | shadcn/ui | MUI |
|---|---|---|---|
| axe 違反 (初期 / ダイアログ / エラー時) | 2 / 0 / 2 | 2 / 0 / 2 | 2 / 0 / 2 |
| 違反の内訳 | `landmark-one-main`, `region` | 同じ | 同じ |
| ↓ と Enter でコンボボックスを選べる | **できない** | できる | できる |
| ← → でタブが切り替わる | **切り替わらない** | 切り替わる | 切り替わる |
| ダイアログの焦点閉じ込め / Esc | はい / はい | はい / はい | はい / はい |

**ライブラリ同士では差が出ませんでした。** shadcn/ui も MUI も同じように正しく動きます。
差が出るのは「手で組んだかどうか」です。

## つまずいた点 (MUI 7 以降)

**システムプロパティが外れています。** 古い記事のコードはそのままでは型エラーになります。

```tsx
// 通らない
<Stack justifyContent="space-between" alignItems="flex-start">
<Typography fontWeight={700}>

// sx に移す
<Stack sx={{ justifyContent: 'space-between', alignItems: 'flex-start' }}>
<Typography sx={{ fontWeight: 700 }}>
```

**DatePicker の入力欄は分割入力です。** 欄をクリックしてもカレンダーは開きません
(月・日・年が別々の要素になっていて、クリックを受け取ってしまう)。
盤面は右端のカレンダーアイコンからのみ開きます。自動テストを書くときはここで詰まります。
