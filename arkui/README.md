## つまずいた点

**コンボボックスは、既定ではクリックしても開きません。** `openOnClick` を付けて初めて
クリックで開きます (キーボードの ↓ では既定で開く)。公式ドキュメントに載っている prop です。

**カレンダーは組み立て式。** `DatePicker.View` × 3 (day / month / year) の中に
`Table` / `TableRow` / `TableCell` を自分で並べます。このぶんで App.tsx が
Radix 回より 138 行伸びました。

**トーストは CSS 変数を受けないと縦書きに潰れます。** Ark は重なり位置を
`--x` `--y` `--z-index` `--opacity` で渡してくるだけで、幅も背景も何も持ちません。
`width: max-content` を忘れると1文字ずつ縦に落ちます (実際に落ちました)。

**フォーム部品 (Field) は検証ロジックを持ちません。** エラー表示の構造だけです。
今回は他実装と条件を揃えるため共有ロジックで検証しました。

## 動かし方

```bash
cd arkui
npm install
npm run dev      # 開発サーバ
npm run build    # 本番ビルド (転送量はこの出力から読んでいます)
npm run preview  # ビルド結果を配信
```

計測とキャプチャはリポジトリ直下から実行します。

```bash
node scripts/measure-a11y.mts arkui 4502
node scripts/capture.mts arkui 4501
```

**実行前に、他の preview が同じポートを掴んでいないか確認してください。**
