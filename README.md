# same-app-every-ui-kit

YouTube「さつきのOSS研究室」の **UI コンポーネントライブラリ検証シリーズ**で使うコードです。
**同じアプリを各 UI ライブラリで作り、同じ条件で見比べる**ためのリポジトリです。

姉妹リポジトリ: [same-app-every-framework](https://github.com/satsuki-c6s/same-app-every-framework)
(こちらは Web フレームワークを同じやり方で比べています)

## このシリーズの主目的

**実際の見た目を見ること。** どんなアイコンで、どんな余白で、どんな動きなのか。
数字はその補助です。数字の大小だけで優劣を決めません。

## 何を作るか

各ライブラリにつきデモを二種類作ります。

### 1. 共通デモ (比べる)

「OSS リポジトリ検索」— 要件は6つだけです。

1. 検索欄で一覧を絞り込む
2. 言語フィルタを切り替える
3. テーブルで表示し、列で並べ替える
4. 行を開くとダイアログが出る
5. 登録フォームを送ると検証エラーとトーストが出る
6. ダークモードを切り替える (公式の機構がある場合のみ)

- データは `shared/data.json` (20件・固定値)。通信なし・API キーなし・毎回同じ結果
- 画面の文言は `shared/copy.json`。**全実装で同一**

### 2. 特徴デモ (比べない)

そのライブラリが公式に売りとして掲げる機能を**1つだけ**見せます。
得意分野が違うものを一列に並べないため、比較対象にはしません。

## 見た目は揃えません (姉妹リポジトリとの違い)

フレームワーク側は CSS を共有して完成画面を完全に同一にしています。
**ここでは見た目こそが評価対象**なので、それができません。代わりに以下を固定します。

- 機能仕様・データ・文言・画面サイズ (1920×1080 / DPR 1)
- 土台のフレームワークとビルドツール・Node・パッケージマネージャ
- 操作手順 (1本のスクリプトが全実装を同じ順で操作します)
- **既定値のみルール** — 公式のスキャフォールドと公式ドキュメントどおりの使い方に限り、
  テーマトークン・配色・角丸・影を手で調整しません。1つでも手を入れると比較が壊れます

見た目の違いは「そのライブラリの既定がそう作られている」ことの表れとして扱います。

## 見る7つの軸

| 軸 | 種別 | 見かた |
|---|---|---|
| デザイン | 見せる | 完成画面を同一構図で並べます。**採点しません** |
| 開発速度 | 実測 | 実装行数・自分で書いた部品数・手数 (コマンド数 + 編集ファイル数) |
| 自由度 | 実測 | 全回同じ改造3課題を公式手順でできるか |
| 技術構成 | 転記 | 公式記載の対応フレームワーク・SSR / RSC |
| アクセシビリティ | 実測 | axe の違反数・キーボードだけで6要件を完遂できるか |
| 保守性 | 転記 | コミット頻度・最新リリース・未解決 issue・ダウンロード数・ドキュメント |
| 必要な部品 | 実測 | 15項目のチェックリストを「無料 / 有料 / 無し」で記録 |

**種別を混ぜません。** 実測はここで測った値、転記は公開情報の写し (取得日つき)、
見せるは点をつけないものです。測り方の定義は [PREREG.md](./PREREG.md)、結果は
[RESULTS.md](./RESULTS.md) にあります。

## キャプチャ

各ライブラリの `<kit>/shots/` に置いています。
**ファイル名は全ライブラリで同じ連番**なので、同じ番号どうしを並べれば同じ場面の比較になります。

- スクリプトの出力だけを置いています (手撮りはしません。条件が揺れるため)
- 1920×1080 / DPR 1 / 同一手順
- 動画はここには置きません。YouTube 側が正本です

## 無料版と有料版

- **有料版のコード・アセットはこのリポジトリに一切含みません**
- 有料版については公式の価格表と機能表を紹介するに留めます
- 凝った部品を有料側に置いているライブラリは、無料範囲だけのデモが公式サイトより
  地味に見えます。**その非対称性は動画内で明言します**
- ライセンスと価格は制作のたびに公式を読み直します (条件は変わります)

## 方針

- 他所のベンチマーク点数は使いません。ここにある数字はすべて自前の実測です
- どれかを貶しません。数字が悪い側には必ず「その代わり何が得られるか」を置きます
- 用途が違うものを一列に並べてランキングにはしません
