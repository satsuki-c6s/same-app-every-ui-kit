## ダッシュボードの部品箱と、止まった時計 (第12回の本題)

Tremor は**ダッシュボード特化**の部品集です。エリアチャート、バーチャート、ドーナツ、
スパークライン。**チャート系だけで11種**あり、この厚みは11実装で唯一です。
すべて無料の Apache-2.0 で、有料版はありません。

配布は shadcn 型の「ソースを取り込む」方式です。ただし **CLI がありません**。
リポジトリや docs から手でコピーします。今回は12部品 + フック + ユーティリティ + 公式 CSS の
**18ファイル・3,307行**を取り込みました。全実装で最大の取り込み量です。

そしてもう1つの発見が保守性です。**直近90日のコミット数が 0**。
2025年1月に Vercel に買収されたあと、旧 npm ライブラリのリポジトリ (スター 16,457) は
2025-01-13 で停止、copy-paste 版の本体も 2025-10-10 が最終更新でした。
docs の Vite ページは「Updating Soon」のまま止まっています。
コードは Apache-2.0 で手元に残るので使い続けられますが、**「動いている OSS」を選びたい人には
そのまま勧められない状態**です。

## つまずいた点

**CLI が無い。** shadcn 型なのに `npx ... add` に相当するものが無く、手でコピーします。
部品間の依存 (DatePicker → Calendar/Popover、Toaster → useToast) も自分で追う必要があります。

**公式の想定は React 18。** 土台の React 19 とは react-day-picker v8 の peer が合わず
`--legacy-peer-deps` が要りました。型の差で Calendar の 1箇所だけキャストを足しています
(それ以外の取り込みソースは無改変)。

**DatePicker の確定は Cancel / Apply の2段階。** 日付を押しただけでは onChange が発火しません。

**`id` は DatePicker のトリガーに転送されない。** ラベル関連付けは公式サポートの
`aria-label` プロップで行いました。

## 動かし方

```bash
cd tremor
npm install --legacy-peer-deps   # 公式指定が React 18 のため
npm run dev
npm run build
```

計測とキャプチャはリポジトリ直下から実行します。

```bash
node scripts/measure-a11y.mts tremor 4510
node scripts/capture.mts tremor 4509
```
